- Installed-plugin runtime loading is now smoke-tested under the dev profile. Full
  hook coverage requires plugin entry hook policy to allow conversation access
  and prompt injection; production config still needs that explicit operator
  setting.
- Spool replay is best-effort from capture hooks and covered by plugin-level outage, replay-failure, and concurrent-capture tests; a full production gateway run is still useful after operator config enables the plugin outside the dev profile.
- The dev compose Postgres volume is persistent; rerun migrations are intended to be idempotent.
- Worker health now includes persistent heartbeat records and long-running handlers can renew job leases; handlers still need workload-specific progress metadata once LLM/evaluation jobs become lengthy.
- Evidence derivation now creates observed event evidence plus deterministic recurring evidence clusters; richer cross-session semantic aggregation and additional contrastive evidence mining beyond evaluator replay maturity remain pending.
- Embedding generation defaults to deterministic local hash embeddings until production provider settings are configured and live-validated; storage now supports profile-scoped variable dimensions, with the default 1536-dimensional path retaining the indexed HNSW fast path.
- Runtime context broker is still conservative: vector fusion is now available for local deterministic hash embeddings, while remote-provider synchronous fusion, broader shadow-edge policy tuning, and historical broker replay gates remain pending.
- External-skill awareness now includes read-only root scanning plus inventory/retrieval/matching, scan scheduling defaults, embedding generation for external descriptions, richer collision risk scoring, and explicit operator review-action recording. Optional operator-approved import materialization remains pending.
